# Учебные криптографические алгоритмы

Оконное приложение на Python 3.10+ и Tkinter. Дополнительные пакеты не требуются.

## Запуск

Из папки `information-security-v2` выполните `py -3 main.py` на Windows или `python3 main.py` в Linux и macOS.

На главном экране выберите один из трёх алгоритмов. Кнопка **Загрузить пример** подставляет параметры и запускает проверку. Все исходные параметры можно менять.

| Алгоритм | Контрольный пример | Результат |
| --- | --- | --- |
| Диффи — Хеллман | `q = 23, g = 5, a = 6, b = 7` | `A = 8`, `B = 17`, оба секрета равны `12` |
| Аддитивный рюкзак | `hi`, `W = (2, 29)`, `m = 409`, `a = 31` | Шифртекст `567 648`, расшифровка `hi` |
| Мультипликативный рюкзак | `hi`, `W = (2, 3)`, `m = 13060694051`, `s = 11` | Шифртекст `5957337453 8496292532`, расшифровка `hi` |

В обеих рюкзачных схемах поле **Основание p** принимает целые числа от 2. По умолчанию `p = 14`. При изменении `p` проверьте условия для ключа и используйте одинаковые `p` и ключ при шифровании и расшифровании. Коды символов идут от `a = 0` до `z = 25`, пробел имеет код `26`.

Кнопки **Зашифровать** и **Расшифровать** работают по отдельности. В поле шифртекста можно ввести блоки вручную через пробел или запятую. **Проверить цикл** шифрует исходное сообщение, расшифровывает результат и сравнивает тексты. Таблица показывает код и цифры блока для каждого символа, шифртекст и промежуточную сумму или произведение при расшифровании.

## Условия для ключей

- В учебной модели Диффи — Хеллмана `q` простое и лежит в диапазоне `5…4294967295`, `g` порождает всю группу ненулевых остатков, а `g`, `a`, `b` лежат в диапазоне `2…q − 2`. Верхняя граница `q` ограничивает время точной проверки генератора.
- В обеих схемах число весов `n` должно удовлетворять `p^n ≥ 27`, чтобы кодировать все символы алфавита.
- В аддитивном рюкзаке каждый вес превышает `(p − 1) ×` сумму предыдущих, `m > (p − 1) × sum(W)` и `gcd(a, m) = 1`. Шифртекст блока хранится как сумма по открытому рюкзаку.
- В мультипликативном рюкзаке используются различные простые веса, простое `m > prod(W)^(p − 1)` и показатель `1 < s < m − 1`. Условие `gcd(s, m − 1) = 1` позволяет однозначно строить открытые веса через обратную степень. Детерминированная проверка простоты используется для чисел меньше `318665857834031151167461`. [Sorenson и Webster](https://doi.org/10.1090/mcom/3134)

Формулы и алфавит взяты из отчёта и задания. Математические модели сверены с первоисточниками. [Диффи и Хеллман](https://cr.yp.to/bib/1976/diffie.pdf) · [Меркль и Хеллман](https://ee.stanford.edu/~hellman/publications/30.pdf) · [Осипян и соавторы](https://vestnik.kubsu.ru/article/download/737/1269/745)

## Тесты

Выполните `py -3 -B -m unittest -v`. Тесты проверяют контрольные примеры, весь алфавит, ошибки ввода и действия кнопок Tkinter.

Для проверки при `p = 3` можно взять примеры из отчёта. Аддитивная схема с `W = (2, 5, 16, 50)`, `m = 149`, `a = 31` шифрует `hi` в `158 218`. Мультипликативная схема с `W = (2, 3, 5)`, `m = 1009`, `s = 5` даёт `934 16`. При расшифровании этих двух блоков получаются произведения `45` и `225`, из которых восстанавливается `hi`.
